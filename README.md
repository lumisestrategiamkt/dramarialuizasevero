## Publicar no GitHub Pages

1. Crie um repositório público no GitHub (ex.: `draluizasevero`).
2. Envie os arquivos desta pasta para a raiz do repositório (`index.html`, `.nojekyll`, `README.md`).
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, branch `main` e pasta `/ (root)`, e clique em **Save**.
5. Em 1 a 2 minutos o site estará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
